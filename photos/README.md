# Photos de l'équipe 📸

Déposez les photos **exactement sous ces noms** (même casse) : le site les affiche automatiquement,
carte membre **et** panneau du département correspondant. Si un fichier manque, le site affiche
discrètement « ? » (carte) ou le logo du club (panneau) — aucun bug visuel.

| Fichier | Utilisé pour |
|---|---|
| `photos/president.jpg` | Carte **Président** |
| `photos/vice-presidente-1.jpg` | Carte **Vice-présidente** — Darine |
| `photos/vice-presidente-2.jpg` | Carte **Vice-présidente** — Ouidad |
| `photos/re.jpg` | Carte **RE** + panneau département RE |
| `photos/rh.jpg` | Carte **RH** + panneau département RH |
| `photos/formation.jpg` | Carte **Formation** + panneau département Formation |
| `photos/media.jpg` | Carte **Média** + panneau département Média |

Conseils :

- Format **.jpg** (un fichier `.HEIC`/`.png` doit être renommé/converti — dites-le-moi et je m'en charge).
- Cadrage plutôt **portrait**, visage dans le tiers supérieur : le site recadre automatiquement.
- Aucune modification de code nécessaire : déposer le fichier suffit.
